## Aurum Launcher 0.4.2

- Account avatars now show the head and outer layer of the current Minecraft skin in the header, Home panel and account list. Pixel-aligned heads, display-scale-aware rendering and subtle frames keep them crisp and compact, with a larger head on Home. Microsoft textures are cached locally; offline profiles use their selected skin.
- The isolated Microsoft sign-in window is prepared in the background and reused between attempts. Preparing the window does not load Microsoft pages or start sign-in.
- Skin preview and appearance controls remain visible while scrolling the skin library, including at the minimum window size.
- Fixed Microsoft sign-in failing when the saved session exceeded the Windows Credential Manager size limit.
- Session tokens now use encrypted local storage. The OS credential vault keeps only a short encryption key and file reference.
- Existing saved sessions migrate automatically. Session updates preserve the previous credentials if saving fails, and removing an account also removes its encrypted session file.

This build also applies the encrypted storage to CurseForge API keys. Game profiles, worlds and account metadata keep their existing locations.
