## Aurum Launcher 0.5.0

### Project catalog

- CurseForge search, project details, installation and update checks now work without a personal API key. Requests use the Aurum gateway; the service key stays on the server.
- Choose **All sources** to search supported platforms together. Each result keeps its platform identity for installation and displays a source logo on its cover.
- Searches run concurrently. If a platform is unavailable, successful results remain visible with an option to retry. Pagination tracks each platform separately.
- Minecraft version filtering excludes Technic from combined modpack searches because its API cannot apply that filter.

### Skins and interface

- Remember the last decoded skin per account across navigation. On a first visit, wait for the appearance and texture instead of briefly displaying a temporary character. Real default skins remain valid.
- Organize the changelog into version sections and show the latest releases in **What's new**.
- Rename the account section to **Profiles**, align the header wordmark using font metrics, and refine instance cards and Play buttons.
