# Aurum Launcher 0.7.3

## Catalog and content installation

- Jump directly to a catalog page, see the total page count and browse without losing your scroll position. Project tiles use larger artwork and consistent hit areas.
- Install from a single project-header button, with instance and version choices in a separate dialog.
- Dependency errors identify the affected addon, missing mod and Minecraft version. Installation reuses verified compatible installed dependencies, including when upstream metadata points to an incompatible version or loader.
- Manually replace modpack files with confirmation, use the refreshed downloads dialog and recover missing CurseForge artwork.
- Install, update and manage resource packs and shaders while Minecraft is running, then apply them in the game's settings.

## Settings profiles and storage

- Keep up to five reusable Minecraft settings profiles, import settings from an instance, edit preferences and select a profile during installation.
- Storage opens with its last disk-usage calculation while refreshing in the background. The component list remains accessible during gameplay.
- Java and file management are grouped in Storage, with more compact launcher settings.

## Screenshots and accounts

- Copy screenshots or save them through the right-click menu; the viewer also has a copy button. Nearby images preload for smoother browsing.
- Incoming friend screenshots require approval. Sound notifications, sender replies and delivery thumbnails make sharing status clearer.
- Open skins and capes from the account card. Skin details include back navigation, and the sneaking preview pose stays active while held.

## Social, updates and launch

- Social invitations reuse a compatible running Minecraft instance instead of starting a second client.
- Social reconnects after restarts and upgrades without asking for P2P consent again. A stable component path preserves firewall setup.
- New launcher versions appear in an update dialog, with options to update and restart or postpone installation.
- A soft two-note chime plays when Minecraft reaches its main menu.

Social remains experimental. Complete Minecraft gameplay and screenshot delivery between separate Internet connections remain unverified.

Windows x64 installer, updater signature, update manifest, Social component assets and SHA-256 checksums are included.
