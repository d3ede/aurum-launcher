## In-app launcher updates

Aurum now checks GitHub Releases automatically on startup and every six hours. When a new version is available, choose **Update and restart** in the banner or under **Settings → Launcher updates**. The launcher downloads the update, verifies its signature, and runs the installer automatically.

- Download progress and retry messages are shown inside the launcher.
- Updates can be postponed. Installation waits until games and current launcher tasks are finished.
- Game data, instances, accounts, and settings keep their existing locations.
- Checks work without a GitHub account or access token. Only signed packages are accepted.

**Upgrading from 0.3.1:** install this version once using **Aurum-Launcher_x64-setup.exe** below. Version 0.3.1 does not include an updater; subsequent versions can be installed from within Aurum.

Release assets include the installer, its updater signature, **latest.json**, and **SHA256SUMS.txt**. The updater signature verifies update authenticity; the Windows installer still does not have an Authenticode publisher certificate.
