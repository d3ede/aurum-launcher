## Aurum Launcher 0.4.1

- Profile folders now use their names, such as `%APPDATA%\Aurum Launcher\instances\My profile`, instead of UUIDs. Existing default data and profiles migrate automatically, preserving worlds, mods, accounts, settings and skins. Custom data locations remain unchanged.
- Renaming a profile also renames its folder. Duplicate names receive numbered suffixes, and characters Windows cannot use in folder names are replaced. Interrupted profile moves resume on the next launch; folders used by a running game wait until a later launcher start.
- Closing an installed mod's project page preserves the mod list and its scroll position. Installing content refreshes the list in the background.
- Modrinth galleries load original images instead of thumbnails, with a larger preview and a viewer that fits the window.
- Fixed image loading in project descriptions, including Imgur images, by omitting local referrers.

If both the old and new default data folders already contain files, automatic migration stops with an explanation instead of overwriting or merging them. Close Minecraft before updating.

Users on 0.3.3 or later can update inside Aurum or download the Windows x64 installer. Release assets include the installer, its updater signature, `latest.json`, and `SHA256SUMS.txt`. Updater signing is separate from a Windows Authenticode publisher certificate.
