## Aurum Launcher 0.4.4

- Drag instances into your preferred order and keep that order across restarts. New instances appear first. Switch between custom, alphabetical and date-added sorting without losing your custom order.
- CurseForge imports preserve the instance, successfully downloaded files and configuration when individual mods require manual downloads or their downloads fail. Missing files are listed with links to their file versions; select a downloaded file to validate and add it. Reopen the missing-file list from the instance later.
- Modpack installation progress shows the pack name instead of only an internal instance identifier.
- Fixed installer sidebar separator generation in Windows PowerShell 5.1.

CurseForge API access still requires an official API key. Author restrictions on third-party downloads remain respected; Aurum does not bypass them. A pack with missing required files may not launch until those files are supplied.
