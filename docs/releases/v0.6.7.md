# Aurum Launcher 0.6.7

- Save mods, modpacks, shaders and resource packs to catalog favorites. Choose compatible versions and install selected projects in a queue; installed projects remain saved.
- Favorites have a simpler layout, per-project installation and a confirmed action to clear selected entries. Manual-download requirements and publisher restrictions are retained.
- Install local Fabric, Forge and NeoForge servers with Minecraft and loader version selection, official installers and a mods folder. Proxy selection is aligned with the hosting form.
- Fixed a first-install failure when duplicate Minecraft assets shared one partial download file. Repeated assets now download once, and concurrent downloads use independent temporary files.

Includes the Social and appearance improvements from 0.6.5. Social remains experimental; completed Minecraft gameplay between separate Internet connections is still unverified.

Windows x64 installer, signed updater manifest and SHA-256 checksums are included. Existing instances, accounts and settings are retained.
