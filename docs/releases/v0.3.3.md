## In-app launcher updates

Aurum now checks GitHub Releases automatically on startup and every six hours. Choose **Update and restart** in the banner or under **Settings → Launcher updates** to download, verify, and install a new version.

- Signed update packages are verified before the installer starts. Altered files and forged manifest versions are rejected.
- Download progress and retry messages appear inside the launcher. Updates can be postponed.
- Installation waits until games and current launcher tasks are finished.
- Instances, accounts, settings, and game data retain their existing locations.
- GitHub Actions builds and signs future releases automatically from version tags.
- Dependency metadata was corrected so a fresh clone can install with `npm ci` and build in CI.

**Upgrading from 0.3.1:** install **Aurum-Launcher_x64-setup.exe** below once to enable future in-app updates. Version 0.3.1 does not contain an updater. The 0.3.2 implementation was not published as a release; this is the first public build with automatic update support.

Assets include the installer, its updater signature, **latest.json**, and **SHA256SUMS.txt**. Update signatures verify authenticity; the Windows installer does not yet have an Authenticode publisher certificate.
