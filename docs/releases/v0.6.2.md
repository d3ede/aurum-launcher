# Aurum Launcher 0.6.2

- Preserve the datapacks folder and its nested files when importing CurseForge ZIPs, Modrinth modpacks and existing game folders.
- Check bundled override paths before contacting download providers. Unsupported paths, traversal, symbolic links and oversized bundled content are rejected before mod downloads begin.
- Validate client-compatible Modrinth manifest paths before downloading files, avoiding a late failure after downloading other mods.

Includes the [0.6.1](v0.6.1.md) fix for CurseForge request limits and all [0.6.0](v0.6.0.md) features. Aurum Social remains an opt-in experiment, **NOT READY for general use**; cross-network Minecraft gameplay still needs two-computer verification after the latest fixes.

Windows x64 installer, signed updater manifest and SHA-256 checksums are included. Existing instances, accounts and settings are retained.
