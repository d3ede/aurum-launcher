## Aurum Launcher 0.3.10

- Browse public ATLauncher, FTB and Technic modpack catalogs alongside Modrinth and CurseForge. Select a pack version and install it into a separate instance without a provider account. ATLauncher includes optional mod selection and a file picker for downloads restricted to the publisher's website.
- Updated project cards with larger icons, responsive tiles, animated installation controls and removal from the selected instance directly from the card.
- Import saved Modrinth skins in one action. Arm models are preserved and duplicate skins are skipped. Saved skin cards now use closer previews.
- Catalog source menus use original platform logos, with balanced FTB sizing and a transparent ATLauncher mark in both themes.
- Minecraft Services sign-in errors now include the HTTP status, the server's error description and a request ID when supplied.

Some historical packs require unsupported legacy patches or custom components; Aurum reports these limitations instead of creating incomplete instances. Provider-restricted files may require a browser download. See [catalog compatibility notes](https://github.com/d3ede/aurum-launcher/blob/v0.3.10/docs/MODPACK-CATALOGS.md).

Existing instances, accounts, settings and game data keep their locations. Shortcut repair from 0.3.9 remains included. Users on 0.3.3 or later can update inside Aurum or download the Windows x64 installer.

Release assets include the installer, its updater signature, `latest.json`, and `SHA256SUMS.txt`. Updater signing is separate from a Windows Authenticode publisher certificate.
