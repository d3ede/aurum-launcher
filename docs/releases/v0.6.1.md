# Aurum Launcher 0.6.1

- Modpack imports and installations wait and retry when CurseForge responds with HTTP 429, preserving download progress.
- The wait follows Retry-After (bounded to 1–300 seconds, with a 60-second default). Each lookup retries up to three times; persistent limits return an error instead of waiting forever.
- Waiting shows a progress message and remains cancellable. Other errors are not retried by this mechanism.

Includes all changes from [0.6.0](v0.6.0.md). Aurum Social remains an opt-in experiment, **NOT READY for general use**; cross-network Minecraft gameplay still needs verification on two computers after the latest fixes.

Windows x64 installer, signed updater manifest and SHA-256 checksums are included. Existing instances, accounts and settings are retained.
