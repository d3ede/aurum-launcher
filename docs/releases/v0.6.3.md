# Aurum Launcher 0.6.3

- Preserve datapacks and custom mod data folders, including fancymenu_data, during CurseForge, Modrinth and folder imports.
- Validate archive paths before mod downloads. Path traversal, archive links and writes to launcher-managed runtime files remain blocked.
- Recognize completed manual downloads by checksum even when their names have changed. Also recognize verified files already placed in the instance.
- Move manual downloads into the instance by default after verifying the copy and saving installation state. Turn off the move option to keep the original; the choice is remembered. Files already inside the instance are retained.
- Keep wrong versions and incomplete downloads out of the installation, and cache download hashes between scans while rechecking files before installation.

Includes the [0.6.1](v0.6.1.md) fix for CurseForge request limits and all [0.6.0](v0.6.0.md) features. Version 0.6.2 was not published. Aurum Social remains an opt-in experiment, **NOT READY for general use**; cross-network Minecraft gameplay still needs two-computer verification after the latest fixes.

Windows x64 installer, signed updater manifest and SHA-256 checksums are included. Existing instances, accounts and settings are retained.
