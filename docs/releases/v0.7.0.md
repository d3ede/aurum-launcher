# Aurum Launcher 0.7.0

## Screenshots and sharing

- Browse screenshots for each instance or across all registered instances. Search, filter by instance, sort and group your library without changing original game files.
- Browse the complete filtered gallery with keyboard or side arrows and smooth transitions. Zoom with the mouse wheel up to ×50, right-click to zoom at a chosen point, and drag enlarged images to pan. The temporary scale indicator is centered in the image viewport; Ctrl+0 restores the fitted view.
- Select up to ten screenshots and send them to an accepted friend. Encrypted copies remain in a durable local queue through restarts and reconnect automatically when both peers are online. Delivery is confirmed after the recipient saves and verifies the attachment.
- Received screenshots have their own library. Save a decrypted copy explicitly or delete the retained encrypted image. No server mailbox is included; delivery waits while either peer has Aurum closed or Social disconnected.

## Skins and instances

- Browse MineSkin, search by name or player, inspect a 3D preview and save skins to the local library with a chosen name. Missing names remain distinct from skin IDs.
- Modpacks use their catalog artwork. New instances receive a random icon with matching colors, and the dice button generates another combination.
- Improved icon selection, loader selectors, skin-browser dropdown sizing and window controls. Instance-opening and launch controls have separate hit areas in compact cards.

## Storage and startup

- A separate Storage page shows disk usage by category, cache and temporary files, installed runtimes and versions, and recoverable deleted content.
- Delete instances or content to the trash, restore selected entries, and confirm permanent removal. Used installations remain protected from individual version deletion; broader category removal requires confirmation.
- Launcher files and game files are separated with upgrade migration. Existing instances, worlds, accounts and settings are retained.
- Compact Java runtimes omit development tools, and installation leftovers are cleaned automatically.
- Microsoft sign-in opens in the regular browser and preserves existing signed-in accounts.

## Smaller distribution

- The Windows release build is optimized for size. Social is an optional, separately downloaded component instead of being included in the release installer.
- Social setup shows progress, supports cancellation and verifies both the compressed download and executable against hashes pinned in the launcher. Matching components are reused offline; component updates may need another download.
- The exact Social assets are published with this release alongside the signed updater manifest and SHA-256 checksums. Local development installers include matching components for offline testing.

Social remains experimental. Screenshot transport has been tested over local QUIC with encrypted storage and verified receipts; complete Minecraft gameplay and screenshot delivery between separate Internet connections remain unverified.

Windows x64 installer, updater signature, update manifest, Social component assets and SHA-256 checksums are included.
