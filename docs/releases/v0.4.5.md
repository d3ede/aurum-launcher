## Aurum Launcher 0.4.5

- Redesigned the instance library with compact horizontal cards, a responsive two-column layout and shared flowing gray background lines.
- Instance cards follow the cursor while dragging, animate into place and retain the saved custom order. Keyboard reordering remains available.
- Added a three-dot action menu to instance cards: open the folder, rename, verify installation or move the instance to trash after confirmation. Actions that cannot run safely while the instance is active are disabled.
- Launch and stop controls stay separate from opening an instance. Card gaps and the trailing arrow open the instance without triggering those actions.
- Added locally bundled circular language icons without text inside the icons. Language search, native names and RTL support remain available; icons require no network downloads.

The language-icon assets retain their upstream MIT license and attribution. Instance files, account settings and existing custom ordering are preserved by the update.
