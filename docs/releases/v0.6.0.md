# Aurum Launcher 0.6.0

## Friends and world invitations (experimental)

- Opt-in Aurum Social with friends, avatars, online/invisible presence and invitation sounds.
- Send world invitations with or without a separate shared instance. Follow delivery and connection status.
- Choose or add a player from an invitation. Instance preparation shows progress and blocks launch until downloads finish.
- The guest opens Minecraft, then selects **Multiplayer → Aurum: <world>** from the LAN list. Keep Aurum open while playing.

**Social remains NOT READY for general use. Cross-network Minecraft gameplay is not yet verified on two computers after the latest fixes.** Public discovery can fail, and direct game connections may be blocked by NAT. An existing user-managed VPN is an optional fallback; Aurum operates no server infrastructure.

The Social network worker runs in Windows AppContainer. Game traffic uses direct authenticated QUIC; optional public relays carry control traffic only. Firewall setup requests elevation once for narrowly scoped rules. See [security boundaries](../SOCIAL.md), [actual test results](../SOCIAL-TESTS.md) and the [two-computer guide](../SOCIAL-TWO-PC.md).

## Installation and updates

Windows x64 installer. Existing instances, accounts and settings are retained. The updater manifest includes a signed installer and immutable version-specific download URL; SHA256SUMS.txt is included for manual verification.
