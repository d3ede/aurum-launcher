## Aurum Launcher 0.3.6

- Selecting a drive in the Windows installer now creates a dedicated folder. For example, `D:\` becomes `D:\Aurum Launcher` instead of placing launcher files in the drive root.
- Explicitly selected folders retain their locations. Browse results and manually entered paths use the same normalization, including UNC share roots and paths containing parent segments.
- Fresh silent installations follow the same folder rule. Automatic updates retain the registered installation location.
- Added installer regression checks to the signed Windows release pipeline.

Existing instances, accounts, settings, and game data retain their locations. Users on 0.3.3 or later can update inside Aurum or download the new Windows x64 installer.

Release assets include the installer, its updater signature, `latest.json`, and `SHA256SUMS.txt`. Updater signing is separate from a Windows Authenticode publisher certificate.
