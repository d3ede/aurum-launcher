## Aurum Launcher 0.4.3

### Local hosting

- Manage existing Minecraft server folders from the new Hosting section, with console output, player actions, file browsing, Java settings and real process measurements.
- Import proxy networks as one card with one launch button. On Windows, explicitly trust an existing BAT, CMD or PowerShell startup file; otherwise, direct-JAR networks start game servers before the proxy.
- Install clean Paper, Purpur, Folia, Vanilla and Velocity distributions from official sources. Spigot links to official BuildTools and imports the resulting server. Velocity is a proxy, and Folia requires compatible plugins.
- Use graceful shutdown, restart and a separately confirmed force action. Startup script stdin stays open to prevent accidental shutdown from EOF. Close, restart and updates are blocked while Aurum-owned servers run.
- Customize profile icons and colors. The dashboard includes a right sidebar, aligned core metrics and subtle green/red status patterns. Fixed network appearance saving with multiline proxy MOTDs and hidden Windows API path prefixes.
- Fixed Velocity player tracking in script-launched networks, including full logger prefixes, split log lines and backend transfers. When the server reports a count without known player names, the UI distinguishes that from an empty server.

### Recent servers

- Home shows up to five servers visited during the past seven days, with their instance, last visit, icon and available status information.
- Join with the matching instance, launch without joining, view the instance, refresh status, copy an address, remove a history entry or create a Windows desktop shortcut.

### Launch preparation

- Reuse cached Java version probes and extracted native libraries when their source files have not changed. Missing or changed files invalidate the cache.
- Read launch credentials once, overlap eligible preparation work and reuse log-redaction patterns. Minecraft and mod initialization still take their normal time; no instant-start guarantee is made.

Imported server files stay in place. Keep Aurum open while hosting; forced launcher termination can terminate its owned server processes. Script-launched component consoles are not individually attached, and unrelated external processes remain read-only. This release does not configure public hosting, firewall rules or port forwarding.
