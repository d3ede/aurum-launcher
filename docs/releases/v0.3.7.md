## Aurum Launcher 0.3.7

This version was not published: the Windows Server shortcut-fixture check stopped the release. Superseded by 0.3.9, which validates Unicode fixtures through the native shell interface.

- Automatic Windows updates now repair existing Aurum Desktop and Start menu shortcuts that still point to an older preview or portable copy in another folder. They are redirected to the updated launcher in the registered installation folder.
- Shortcut icons and working directories tied to the old executable follow the updated installation. Arguments, hotkeys, descriptions, custom icons and custom working directories are preserved.
- Deleted shortcuts are not recreated, saved shortcut choices are retained, and `/NS` continues to skip shortcut changes. Links targeting other products are left alone.
- Added native shortcut regression checks to the signed Windows release pipeline.
- Completed English labels for installed content management and settings.

Existing instances, accounts, settings and game data retain their locations. Users on 0.3.3 or later can update inside Aurum or download the Windows x64 installer. The shortcut repair is included in this installer, so it applies when upgrading from earlier versions; the old launcher does not need to contain the fix.

Release assets include the installer, its updater signature, `latest.json`, and `SHA256SUMS.txt`. Updater signing is separate from a Windows Authenticode publisher certificate.
