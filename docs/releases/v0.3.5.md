## Aurum Launcher 0.3.5

- Redesigned home page with compact account and release panels, direct instance settings, and subtle line-and-pixel patterns in both themes.
- Installed content manager with project icons, readable versions, search, sorting, and state/source/author filters.
- Recognition of imported Modrinth files and local Fabric, Quilt, Forge, and NeoForge metadata. Compatible updates can be installed individually or together; disabled mods stay disabled.
- Catalog list and grid views, localized filters, source logos, image carousels, and image zoom.
- Compact Windows installer with folder selection, independent Desktop and Start menu shortcuts, automatic display-language selection, and an improved close control.
- Updated English README preview. Test screenshots are now stored locally rather than in the source repository.

The Windows x64 setup includes the launcher interface. Minecraft, Java, loaders, and mods are downloaded separately. Existing instances, accounts, settings, and game data retain their locations.

Users on 0.3.3 or later can update inside Aurum. Older installations require running the setup once. Release assets include the installer, its updater signature, `latest.json`, and `SHA256SUMS.txt`. Updater signing is separate from a Windows Authenticode publisher certificate.
