# Aurum Launcher 0.7.4

## Launcher settings

- General settings save automatically, including memory, game-window dimensions and JVM arguments. Edits are kept when navigating between pages and merged with the latest saved settings. Invalid dimensions leave the previous valid value intact.
- A compact settings panel offers separate switches for the Minecraft readiness sound and launcher notification sounds. Both are enabled by default.
- Optionally minimize Aurum when Minecraft starts, restore it after the last game exits, confirm before closing, or remember the last open page. These options are off by default.
- Disable all launcher animations, including character motion in 3D skin previews, with a separate switch that is off by default.
- Settings use the available window width. Switch icons align with their labels, and manual-save controls have been removed from general settings.

## Interface and screenshots

- The outer application frame disappears when the window is maximized or fullscreen.
- Hosting action buttons retain readable contrast across built-in themes and custom accent colors.
- Install buttons reveal a soft circular hover color from the pointer position over 1.6 seconds. The effect follows the cursor and respects reduced-motion preferences.
- Screenshot paging no longer highlights the viewer's Close button. Screenshot search has a single focus outline.

## Recent servers and Social

- Recent servers refresh their saved names and icons from Minecraft without another connection, including when a server is offline. This fixes stale artwork in server history.
- Standalone local builds embed and verify their Social runtime, avoiding mismatched downloads from an older published release. Download errors explain how to recover. Public releases continue to use their version-pinned optional Social assets.

Social remains experimental. Complete Minecraft gameplay and screenshot delivery between separate Internet connections remain unverified.

Windows x64 installer, updater signature, update manifest, Social component assets and SHA-256 checksums are included.
