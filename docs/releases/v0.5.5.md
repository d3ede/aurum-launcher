# Aurum Launcher 0.5.5

Horizon instances, native mod compilation and clearer control over game data.

- Create a Horizon instance for Minecraft 26.3. The optional engine downloads on demand, verifies upstream signatures and requires a Microsoft account owning Java Edition.
- Find native Horizon mods in their own catalog. Installing downloads sources; **Compile** builds the enabled selection with progress, logs and cancellation. Before playing with uncompiled changes, choose to compile or start the base game without user mods.
- The first native mod build downloads its tools and can take 20–30 minutes or longer and several GB. Java mods are not compatible with Horizon; older pinned native mods may need a newer version supporting Aurum's Launch API.
- Original loader logos and tintable Vanilla, Fabric, Forge, NeoForge, Quilt and Horizon instance symbols.
- Cached skin previews no longer wait for cape downloads, while chosen appearances remain visible across navigation.
- Reuse compatible Java runtimes and remove installation ZIPs only after validation. Imports keep the original by default, with optional recycling after a verified copy.
- Uninstall from Settings, Start or Windows Apps. Game-data removal is a separate unchecked choice; ordinary updates and silent removal preserve it.

Includes the 0.5.0 improvements: CurseForge without personal API keys, combined catalog search, updated instance cards and versioned release notes.

Windows x64. Full authenticated Horizon gameplay and complete native mod compilation remain manual verification items; compatibility with every registry mod is not guaranteed. See the [Horizon guide](https://github.com/d3ede/aurum-launcher/blob/v0.5.5/docs/HORIZON.md).

The release provides the signed updater installer, detached signature, update manifest and SHA-256 checksums. The updater signature is separate from Windows Authenticode signing.
