## Aurum Launcher 0.4.6

- Fixed CurseForge imports placing resource packs and shaders in the mods folder. Project metadata selects the correct folder; ZIP contents provide a fallback when project metadata is unavailable.
- While the missing-files dialog is open, Aurum checks Downloads for the required files and imports only checksum-matching versions. Browser-renamed duplicates are supported; incomplete downloads and unrelated files are ignored. Manual selection remains available.
- Added an opt-in option to remove matched source downloads only after successful import. Source downloads are kept by default.
- Removed the quick-launch instance from Home's recent list, leaving room for other instances.
- Aligned Home with the search area, made quick launch more compact and separated instance-card hover styling from the Play button.

This update does not automatically relocate content in previously imported instances. Existing instance files, account settings and custom ordering are preserved.
