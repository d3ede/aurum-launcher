# Language picker icons

The SVG files were generated without modifications using the templates, colors, and generator from [AnandChowdhary/language-icons](https://github.com/AnandChowdhary/language-icons/tree/518a8effbfbae69e1bfb3bc7485e323c4b91f4b5), revision `518a8effbfbae69e1bfb3bc7485e323c4b91f4b5`, under the MIT license. See [LICENSE](LICENSE) for the complete upstream notice.

Only the 40 ISO 639-1 icons used by the launcher's language registry are bundled (16,349 bytes in total). Both Chinese script variants share `zh.svg`. The picker applies circular clipping with CSS, as shown in the upstream example. All icons are bundled locally and require no network requests or additional runtime dependency.
