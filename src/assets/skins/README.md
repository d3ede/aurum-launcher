# Default Minecraft skins

Original Minecraft Java Edition 1.21.1 textures, extracted without modification from the official client already downloaded by this launcher's verified Minecraft installation.

- `steve.png`: `assets/minecraft/textures/entity/player/wide/steve.png`.
- `alex.png`: `assets/minecraft/textures/entity/player/slim/alex.png`.
- Source client JAR SHA1: `30c73b1c5da787909b2f73340419fdf13b9def88`.

Minecraft textures belong to Mojang/Microsoft; they are not original Aurum artwork. These two textures are used for the Minecraft account preview. Their corresponding models are classic and slim, respectively. Uploaded user skins take precedence.

The wardrobe also bundles all nine default characters (Steve, Alex, Ari, Efe, Kai, Makena, Noor, Sunny, Zuri), in both wide and slim variants. The 18 `wide-*.png` / `slim-*.png` files were extracted without modification from `assets/minecraft/textures/entity/player/{wide,slim}/` in the official Minecraft Java 26.3 client already downloaded by the launcher's verified installer. Client JAR SHA1: `e877b6a07acd633fb3bb475002175cec036e7b87`. The textures remain Mojang/Microsoft assets. Skin thumbnails are rendered locally by Aurum; Modrinth code or graphics are not used.
