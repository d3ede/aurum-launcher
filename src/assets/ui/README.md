# Interface artwork

`game-die.svg` is the unmodified **Game die / Color** artwork from
[Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji/blob/main/assets/Game%20die/Color/game_die_color.svg),
downloaded on 2026-11-08. Its original geometry, perspective, pips and soft
shading are preserved. The selector uses the same 21 px slot as neighboring
symbols. CSS slightly reduces opacity and saturation to soften contrast against
the lavender tile, and applies a rigid rotation when the randomizer is clicked.
