# Interface artwork

`game-die.svg` is the unmodified **Game die / Flat** artwork from
[Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji/blob/main/assets/Game%20die/Flat/game_die_flat.svg),
downloaded on 2026-11-08. Its original geometry, perspective, pips and colors
are preserved. CSS controls its display size and applies a rigid rotation
when the instance-icon randomizer is clicked.
